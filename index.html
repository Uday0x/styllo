Zero config · Pure HTML

Style HTML with chai-

A lightweight, class-driven styling engine by Styllo. Drop a chai- prefix on any element and watch it style itself — no build step, no config, pure simplicity.

Write this HTML

<!-- just add chai- classes -->
<div class="chai-p-20 chai-flex chai-ai-center">
  <h1 class="chai-fs-32 chai-center">
    Hello, Styllo ✨
  </h1>
  <p class="chai-bg-yellow chai-p-10">
    Styled instantly.
  </p>
</div>

02

How it works

01

Import the script

Install via npm i styllo-css, then import and call initialize() — or let DOMContentLoaded handle it automatically.

02

Add chai- classes

Write classes like chai-p-20, chai-flex, or chai-bg-red directly on your HTML elements.

03

Styles apply instantly

The engine scans, maps each chai-* class to an inline style, then removes the class. Clean, no residue.
